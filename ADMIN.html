Заказы обновляются сами каждые 5 секунд, на новый заказ — звук и вибрация. Пока вкладка админки открыта.

Подключение базы (один раз)
  1. console.firebase.google.com → создать проект.
  2. Build → Realtime Database → Create database.
  3. Вкладка Rules → вставь правила ниже → Publish.
  4. Build → Authentication → Email/Password включить → Users → Add user (твой email и пароль для входа сюда).
  5. Адрес базы и Web API Key (Project settings) впиши в firebase.js.
